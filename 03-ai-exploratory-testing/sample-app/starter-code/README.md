# Starter Code

This folder provides a clean snapshot of the exploratory testing demo app before executing the scenarios.

## Included
- Django project files (`config/`, `api/`, `middleware/`, `manage.py`, `requirements.txt`)
- The intentionally vulnerable middleware implementations used for the demo

## Not included
- `scenarios.txt`
- `test_results.txt`
- `output.txt`

Those belong to the generated/final-output stage, not the starter state.
